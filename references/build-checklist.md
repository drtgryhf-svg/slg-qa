# 版本/包体质检清单

适用场景：提审前检查、发版前回归、新包回验、hotfix 验证。逐项核对，不适用于此清单的问题走对应质检线。

## 1. 包体基础

- [ ] `versionCode` / build 号严格递增，与提审后台填写一致
- [ ] `versionName` 正确（hotfix 带后缀如 `2.3.1-hf1`，不要出现 dev/beta 字样）
- [ ] `packageName` / `bundleId` 与对应渠道/市场一致（**拿错包提审是最经典的 P0**）
- [ ] 正式签名，非 debug 签名，`debuggable=false`，无测试后门开关残留
- [ ] 包大小：Google Play AAB base module ≤ 200MB、总包 ≤ 4GB；iOS 蜂窝网络下载限制（200MB 历史线，现放宽但仍影响转化）
- [ ] `minSdk`/`targetSdk` 满足商店当年最低要求（Google Play 每年上调 target API，提审前查最新公告）

## 2. 资源与商店展示

- [ ] 应用图标各分辨率正确、圆角合规（iOS）
- [ ] 启动图/闪屏正确，无上一版本活动残留
- [ ] 应用名按语言本地化（`strings.xml` / `InfoPlist.strings`），商店后台名称与包内一致
- [ ] 商店截图/视频为当前版本内容，无过期活动画面（提审被拒常见原因）
- [ ] 首次启动：无白屏/黑屏卡顿、无启动即弹评分（App Store 审核红线）

## 3. 权限与隐私

- [ ] Android Manifest / iOS Info.plist 权限最小化：申请的每个权限都有对应功能，无"顺手申请"
- [ ] 权限用途文案本地化且与实际用途一致（iOS 权限弹窗文案会被审核看）
- [ ] Apple Privacy Manifest（`PrivacyInfo.xcprivacy`）覆盖所有第三方 SDK 的 required-reason API
- [ ] Privacy Nutrition Label（数据收集声明）与实际 SDK 行为一致
- [ ] 隐私政策 / 用户协议链接可达、语言与商店地区匹配、版本已更新
- [ ] 账号删除入口存在且可用（Google Play 与 App Store 双端硬性要求）

## 4. 更新与兼容

- [ ] 强更弹窗：版本判断逻辑正确（含 hotfix 号比较）、跳转商店链接对应正确市场
- [ ] 热更：CDN 资源版本号递增、完整性校验、热更失败有兜底（可进游戏或可重试）
- [ ] 存档兼容：旧版本账号升级进新版本，资源/进度/邮件不丢
- [ ] 跨版本灰度：新旧版本同时在线时，新活动对旧客户端的表现（不崩溃、有兜底文案）
- [ ] 断网/弱网：冷启动断网、登录中断网、热更中断网的兜底

## 5. SDK 与支付

- [ ] 支付：沙盒/生产开关确认为生产，商品 ID 与商店后台一致，掉单恢复逻辑可用
- [ ] 广告：测试广告位全部替换为正式广告位，测试模式关闭
- [ ] 数据上报：安装/注册/付费关键事件各打一条验证到达
- [ ] 推送：各市场证书/渠道配置有效，多语言推送文案走完 LQA（引用 lqa-checklist.md）
- [ ] 客服/FAQ/社区入口链接可达（Discord/FAQ 域名过期是真实发生的 S3）

## 6. 提审材料核对

- [ ] 版本说明（What's New）已写、已本地化主要语言
- [ ] 分级问卷与实际内容一致（暴力度、赌博元素——开箱类必须勾选）
- [ ] 概率公示页面版本与本次新卡池/新宝箱对齐
- [ ] 审核备注（Review Notes）提供测试账号、支付测试说明
