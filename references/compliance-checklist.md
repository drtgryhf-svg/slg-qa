# 国际合规质检清单

适用场景：新市场上线前、提审前风险检查、概率/隐私相关改动后。**合规问题一律 S2 起评**——功能能用但违规，等于不能上线。

## 按市场必查项

| 市场 | 必查项 |
|---|---|
| 欧盟/EEA | GDPR 同意弹窗（拒绝与同意同等难度）、数据可携/被遗忘权入口、DSA 条款、PEGI 分级与内容一致、loot box 概率披露 |
| 英国 | UK GDPR、Age Appropriate Design Code（未成年人默认隐私保护） |
| 美国 | COPPA（13 岁以下保护）、ESRB 分级问卷真实、FTC loot box 指引、CCPA/各州隐私法（do not sell 入口） |
| 韩国 | **확률형 아이템 확률 표시（概率公示为法律强制）**、게임산업법 시간선택제（未成年宵禁，现取决于自我约束）、本인인증流程 |
| 日本 | 景品表示法（コンプガチャ禁止——完整卡池循环抽取违规）、資金決算法对月卡/虚拟货币的表示义务、CERO 分级 |
| 德国 | USK 分级、纳粹/极端符号法律红线（即使游戏内"历史还原"也不行）、 loot box 概率披露（2023 年起部分义务） |
| 中东 | 宗教符号与内容敏感、斋月期运营素材、MENA 分级（部分地区） |
| 巴西 | 分级（ClassInd）、pt-BR 消费者保护（退款政策展示） |
| 印度 | 地图边界（克什米尔表述会导致下架）、自评级（Self-Regulatory Body） |
| 中国台湾 | 分级标示、概率公示（网游规范） |

## 通用硬性项（全市场）

- [ ] 隐私政策 + 服务条款：链接可达、生效日期更新、有目标市场语言版本
- [ ] 账号删除功能：入口可发现、流程可用、数据删除范围说明
- [ ] **概率公示**：抽卡/宝箱/转盘概率在游戏内可达页面公示，概率数值与配置一致，每次新卡池同步更新
- [ ] 年龄分级闸门：分级问卷与实际内容一致（开箱/抽卡必须勾选模拟赌博项）
- [ ] 未成年人保护：年龄询问/家长同意流程、付费限额提示
- [ ] 广告标识：插屏/激励视频广告有"广告"标识（部分地区强制，如荷兰对儿童向）
- [ ] 付款展示：价格含税表述（澳/欧盟消费者法要求含税价）、订阅类明确周期与取消方式
- [ ] 数据收集清单：SDK 清单与隐私政策披露一致（新增 SDK 忘更新政策是高频 S2）

## 检查方法

1. 先按**目标市场**定位到表格行，逐项核对
2. 通用硬性项全查
3. 涉及概率/隐私/分级的任何改动，回归本清单对应条目
4. 输出：合规风险清单（每条注明违反的市场 + 法规依据 + 证据截图/页面路径），按 S2 起评写入 bug 单
