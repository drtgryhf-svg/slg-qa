# 本地化质检清单（LQA）

国际服 SLG 的本地化检查清单。标注【脚本】的项目由 `scripts/lqa_scan.py` 覆盖，标注【AI】的项目需要人工/AI 判断，标注【截图】的项目需要看 UI 截图。

## A. 机器可查项【脚本】

1. **占位符完整性**：`{0}` `{1}`、`{name}`、`{{var}}`、`%s` `%d` `%1$s`、`<color=xxx>`、`<b>` 等标签——目标语言与源文必须一一对应，数量一致、名字一致。占位符丢失或被翻译（如把 `{0}` 写成 "0"）是 P0 级 LQA bug。
2. **未翻译串**：目标列为空、目标 == 源文、目标只是大小写变化。注意专有名词（联盟名、玩家名、英雄名）会造成误报，需要人工复核脚本标出的项。
3. **术语一致性**：对照术语表——required 术语必须出现，forbidden 术语禁止出现。典型 SLG 案例：同一 "Alliance" 在德语里被不同供应商译成 `Allianz`/`Gilde`/`Clan` 混用。
4. **文本超长**：按语言膨胀系数与源文长度比（默认系数见脚本内置表，de ×1.4、ru ×1.2、fr/es/pt ×1.25、ja/ko ×1.0、ar ×1.3）。文本表带 max-length 元数据时直接按上限判。
5. **空格与标点**：首尾空格、连续空格、重复标点（`！！` `。。` `..`）、源文句号目标丢失。
6. **转义与标签配对**：`\n` `\t` `\"`、HTML/富文本标签开闭配对、标签数量一致。
7. **编码异常**：U+FFFD 乱码、夹带 bidi 控制符（U+200E/200F/202A-202E）、全半角混用（ja/zh 正常使用全角不算）。
8. **大小写风格**：源文 Title Case 而译文全小写之类风格漂移（en/de/fr/nl 适用）。

## B. 语言质量【AI】

- **数值语义**（SLG 最高频雷区，逐条核对）：
  - `increases attack **by** 10%`（+10）vs `**to** 10%`（变成 10）——by/to 混译直接导致玩家误解数值
  - `up to 100`（上限）vs `100`（固定值）；`per hour` / `per 10k` 的分母
  - 数值单位：K/M/B vs 万/亿 的换算与显示口径，大数值截断（999.99K 显示成 1M 属于显示 bug）
  - 百分比与千分号方向：`10%` vs `%10`（部分语言语序不同）
- **译文准确**：数字、单位、否定、条件句（if/unless/until）不译反、不漏译
- **术语近义词漂移**：脚本查不到的近义词（如 march / troop movement 混用），按概念全文统一
- **语气与称呼一致性**：de 统一 Sie 或 du 不要混用；fr 统一 tu/vous；ja 敬语等级统一（です・ます 基调）；ko 해요체/합쇼체 统一；es 采用 es-419 中性表述，避免 es-ES 的 vosotros
- **风格指南符合度**：如有 style guide，抽查高频 UI 文案（按钮、弹窗标题）是否符合

## C. UI 与显示【截图】

- **截断/溢出**：按钮、页签、弹窗标题、行军条、资源条最易炸；de 合成词、ru 长变格、nl 复合词优先看
- **RTL**：阿拉伯语布局镜像、括号方向、图文混排方向、进度条方向
- **字体回退**：泰文声调、越南文多层声调、韩文旧字形、emoji 回退（豆腐块）
- **换行**：泰语无空格断词、日语禁头禁尾字符（「、。不可开头）
- **动态文本**：最长玩家名/联盟名塞进模板后的表现（`{player_name} 攻打了 {alliance_name}` 类句子）

## D. 本地格式约定【AI + 脚本辅助】

- **日期/时间**：M/D/Y vs D/M/Y、12h/24h、时区标注口径（服务器时间 UTC / 当地时间必须全文统一）
- **货币**：符号位置（$100 vs 100$）、小数位、用符号还是 ISO 代码（高档位礼包建议 ISO 代码避免歧义）
- **标点**：zh 全角、fr 冒号/问号前空格、es 开头 ¿¡、de 引号 „"
- **复数**：pl/ru/ar 多复数形式是否走对 key（脚本难查，抽走高修改量的 key）

## E. 文化与敏感【AI】

- **符号**：宗教符号误用、国旗错误（用错旗帜是国际服 S2）、纳粹/极权相关符号（de 市场法律红线：万字、SS 阵型图标类）、骷髅/血腥是否符合目标分级
- **颜色与手势**：OK 手势（南美部分市场负面）、绿色在穆斯林市场的正面语义（可用但别乱玩梗）、白色（东亚丧葬关联）
- **政治与地图**：地图边界（克什米尔、南海诸岛、库尔德地区——地图类素材必须逐张核）、历史人物与事件表述（KvK 文明题材高发）
- **UGC 过滤**：联盟名/玩家名/聊天过滤词库各语言覆盖度，抽查测试敏感词

## F. 各语言高危点速查

| 语言 | 高危点 |
|---|---|
| de | 复合词超长、Sie/du 一致、名词大写、变格 |
| ru | 占位符周围词形变化（变格）、长度膨胀 |
| fr | `:;?!` 前空格、省文撇 `'` vs `'`、长度膨胀 |
| es | ¿¡ 配对、es-419 vs es-ES 词汇（computadora/ordenador） |
| pt | pt-BR vs pt-PT 词汇混用 |
| it | 长度膨胀、介词缩合 |
| ja | 全半角、敬语、汉字表记（字体简繁混排）、`・` 间隔号 |
| ko | 敬语体统一、语序导致占位符重排 |
| zh | 简繁混用、全半角、「的/地/得」 |
| ar | RTL、占位符语序、东阿拉伯数字（٠١٢ vs 012） |
| tr | İ/i 大小写转换 bug（locale-aware 大小写）、后缀黏着 |
| id/th/vi | 声调符号渲染、断词、长度 |
| pl/uk | 多复数、变格 |
